Payload-заметки iOS-дева — BAS-741

Новые/изменённые поля payload. Reference на будущее: что мы сможем использовать в темплейтах.

Источник: блок NOTES в BAS-741 (от iOS-дева). Зашипано на develop + hotfix/v1.43.2. Бэкенд-миграция: docs/specs/BAS-748-payload-changes.md (в репозитории iOS/бэкенда). payloadVersion = 1.

⚠️ Изменение смысла существующих полей

Важно: смысл уже существующих полей поменялся — старая логика темплейтов, опирающаяся на них, может «поехать».
  • estimate.totalCost → теперь raw catalog (без зоны, без дисконта). Прежний смысл переехал в zoneAdjustedTotalCost.
  • item.total → теперь zone-insensitive (raw, без зоны).
  • Legacy totalCostCashDiscount / totalCostDepositDiscount / totalCostBothDiscounts / totalCostAllDiscounts — не трогали, работают как раньше.

Новые поля — на уровне estimate

ПолеНазначение
zoneAdjustedTotalCost, zoneAdjustedDiffИтог с учётом зоны + разница от raw
totalWithAllDiscounts, allDiscountsDiff, finalTotalCostИтог со всеми дисконтами, разница и финальная цена
appliedDiscounts[].diffFromZoneAdjustedКаждая запись дисконта расширена разницей от zone-adjusted
payloadVersion, calculatedAtВерсия payload (=1) и ISO8601-время расчёта

Новые поля — на уровне item

ПолеНазначение
zoneAdjustedTotal, zoneAdjustedDiffИтог по айтему с учётом зоны + разница
totalWithAllDiscounts, allDiscountsDiff, finalTotalСо всеми дисконтами, разница, финал
discountBreakdown[]По записи на каждый применённый дисконт: totalWith (изолированно) + diffFromZoneAdjusted
maxRefundAmountТолько для proposal; на change orders опускается

Что это даёт в будущем

  • Можно показывать цепочку цен: raw catalog → zone-adjusted → final с дисконтами.
  • Детальная разбивка по каждому дисконту (discountBreakdown[]) — например, отдельной строкой/блоком.
  • Версионирование payload (payloadVersion) — можно ветвить логику темплейта по версии для обратной совместимости.
  • calculatedAt — печатать дату расчёта на документе.
